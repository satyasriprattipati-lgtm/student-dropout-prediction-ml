# 🎓 Student Dropout Prediction - ML

Student Dropout Prediction using Machine Learning

## 🚀 Live Demo
**👉 https://student-dropout-prediction-ml-ewht4ej6nejdzfo23xhn8j.streamlit.app**

## 📌 Project Overview
Ee project lo student details (marks, attendance, tuition fees, scholarship, age etc.) batti aa student **Dropout / Enrolled / Graduate** avthado predict chestham.

## 📊 Dataset
- **Source:** UCI Student Dropout Dataset
- **Total Students:** 4424
- **Target:** Dropout / Enrolled / Graduate

## 🧠 Model
- **Algorithm:** Random Forest Classifier
- **Features:** Marital Status, Application Mode, Course, Previous Grade, Admission Grade, Age, Tuition Fees, Scholarship, Debtor, Gender, 1st & 2nd Sem Grades / Approved Units

- Python, Pandas, Scikit-learn, Streamlit
